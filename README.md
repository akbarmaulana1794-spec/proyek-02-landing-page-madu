# Landing Page - Madu Hutan Sumbawa

Landing page untuk UMKM Lokal penjual madu hutan asli dari sumbawa, NTB. Dibangun sebagai simulasi proyek klien nyata dengan fokus mengarahkan pengunjung memesan langsung lewat WhatsApp.

## Fitur

- Hero section dengan value proposition jelas dan tombol CTA WhatsApp
- Section keunggulan produk berdasarkan fakta konkret, bukan klaim generik
- Katalog produk dengan link pesan WhatsApp yang otomatis terisi 
- Testimoni pelanggan
- Layout responsif menggunakan CSS Flexbox

## Teknologi 

- HTML5
- CSS3 (Box Model, Flexbox)

## Yang saya pelajari 

Proyek ini melatih saya berpikir seperti problem solver sebelum menulis kode -- memahami kebutuhan bisnis klien, menerjemahkannya jadi struktur halaman, dan memastikan setiap klaim yang diltulis bisa dipertanggungjawabkan secara etis.
